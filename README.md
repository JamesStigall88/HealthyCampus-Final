# HealthyCampus-Final
This iOS app (named "Rest Up, Cool Down") was built to improve users' sleep and to support their mental health

It was particularly built for the 2026 App Design Challenge held back in April of 2026.

Below is the link to the presentation for the project made during the challenge.
